# The repository every report fixture was recorded against (A-616). make-fixtures.py builds it with stock svnmucc over
# file://, one svnmucc commit a revision, then sets each revision's svn:date with svnadmin setrevprop; the tests build
# the same history into the index (A-553) and their model of the tree, so the two are one history by construction.
#
# Grammar, one revision a block:
#   revision AUTHOR DATE                 the revision's svn:author and svn:date
#   mkdir PATH                           svnmucc's actions, PATH relative to the repository's root
#   put PATH TEXT                        TEXT the rest of the line, with the escapes \n \t \\ and \xHH
#   put PATH bytes:N                     the bytes 0 to N - 1 (N at most 256)
#   put PATH lines:N                     N numbered lines, "line I of a text long enough to need several windows\n"
#   put PATH lines:N:edit:I              the same with line I as "line I, edited on the branch of history\n"
#   rm PATH
#   cp REV SRC DST
#   mv SRC DST
#   propset NAME VALUE PATH              VALUE holds no blank
#   propdel NAME PATH
# Blank lines and lines starting with # are ignored.
